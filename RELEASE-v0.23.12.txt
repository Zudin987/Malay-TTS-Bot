Malay TTS Bot v0.23.12 — Gemini Live-First Read-Aloud

Main change
- Every normal user-authored Discord message now tries Gemini 3.1 Live first regardless of wording, punctuation, question form, Malay particles, or assistant-like phrasing.
- Removed content-based provider bypasses that previously sent messages beginning with words such as "ada", "dah", "belum", and "boleh" away from Gemini Live.
- Questions such as "ada event apa", "what current event?", and assistant-like text such as "tell me a joke" now still use Gemini 3.1 Live first.
- Internal recovery/fallback items may still explicitly skip Live so a recovered tail is not sent through the conversational model again.
- The strict read-aloud system instruction remains responsible for making Gemini speak the transcript instead of answering it.

Important trade-off
- Gemini Live is a conversational native-audio model. Prompting strongly reduces assistant-style answers, but zero-answer behavior cannot be mathematically guaranteed while preserving immediate streaming playback. Fully validating speech before playback would add latency and is intentionally not enabled.

Compatibility
- Provider order remains Gemini 3.1 Live -> Gemini 2.5 Live -> Gemini 3.1 TTS -> Google Malay.
- Recovery hardening from v0.23.11 is unchanged.
- Speaker labels, key selection, queueing, and voice configuration are unchanged.

Upgrade
Preserve .env and data\guilds.json. Use the new release files. Existing v0.23.11 config/settings.json remains compatible because this routing change is code-level.
