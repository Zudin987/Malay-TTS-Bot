Malay TTS Bot v0.23.18

Changes
- Fixes a rare /ask mismatch where Gemini Live could interpret the displayed AI reply as conversational input and speak a different answer.
- /ask speech now skips Gemini Live and uses the dedicated Gemini 3.1 TTS model first, with Google Malay TTS as fallback.
- The exact displayed AI reply remains the only text queued for /ask speech and verification.
- Normal Discord message TTS remains Live-first with the existing provider order and latency behavior.
- STOP TTS behavior is unchanged. Discord does not expose pixel-level ActionRow/button alignment, so the small visual offset relative to the embed remains client-controlled.

Why
Generated /ask text is already final content. Sending it back through a conversational Live model can occasionally cause semantic interpretation instead of literal read-aloud. Dedicated TTS is the safer path for exact spoken parity with the embed.
