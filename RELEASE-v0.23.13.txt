Malay TTS Bot v0.23.13 — Concise /ask Chat

Main change
- Adds /ask question:<text> as an explicit AI answer mode while normal Discord messages remain read-aloud TTS only.
- /ask uses stable gemini-3.1-flash-lite text generation with minimal thinking for low latency.
- Default answers are concise chat replies, normally one to three short sentences.
- The /ask system instruction forbids article-style headings, bullet/numbered lists, tables, citations, embeds, image generation, image suggestions, and unnecessary background.
- A hard output compactor removes image/list/article formatting and caps the final Discord answer at 450 characters by default.
- Generated Discord mentions are disabled.
- /ask makes one Gemini request per command and reports concise timeout/quota/auth/block failures.

Configuration
- New config/settings.json ask block controls enabled, model, timeoutMs, maxQuestionCharacters, maxOutputTokens, maxAnswerCharacters, temperature, and thinkingLevel.
- /ask settings are normalized and hot-reloaded with the rest of settings.json.
- Existing settings.json files without an ask block remain compatible and use safe built-in defaults.

Compatibility
- TTS provider order and Gemini Live-first read-aloud behavior from v0.23.12 are unchanged.
- Speaker labels, recovery hardening, queueing, voices, and normal TTS messages are unchanged.
- No new npm dependency or local AI component was added.

Upgrade
Preserve .env and data\guilds.json. Existing config/settings.json is compatible; keeping it preserves your local tuning and /ask will use built-in defaults when its block is absent. Run setup-clean.cmd so the new slash command is deployed.
