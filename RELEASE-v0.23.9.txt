Malay TTS Bot v0.23.9 — Fidelity Prompt Profiles

Highlights

- Gemini Live and Gemini 3.1 TTS now use separate prompt profiles instead of sharing one long instruction set.
- Live uses a shorter fidelity-first system instruction plus collision-resistant per-turn speech boundaries.
- Gemini 3.1 TTS uses a TTS-specific AUDIO PROFILE / DIRECTOR'S NOTES / TRANSCRIPT request structure.
- Strict read-aloud rules prioritize preserving lexical content and order and explicitly prohibit invented content, answers, translation, completion, paraphrase and rewriting.
- Malaysian Malay, English and Manglish pronunciation remains neutral, calm and approximately 0.95x conversational pace.
- Complete square-bracket spans are neutralized for Gemini audio only so native audio-control syntax such as [laughs] is spoken as lexical text rather than executed as a performance direction. Google Malay fallback text is unchanged.
- Existing collision-safe SPEECH_TEXT_START/END nonce boundaries remain in place.
- Existing top-level Gemini TTS prompt overrides remain backward-compatible.
- Editable defaults now live independently under geminiLive.profile and geminiTts.profile in config/settings.json.

Regression coverage

- Separate Live and exact-TTS profile normalization.
- Collision-resistant transcript boundaries.
- Square-bracket audio-tag neutralization.
- Malay shorthand input such as “aku nk pergi kedai” is not expanded into additional words such as “ke”.
- Prompt builders contain no injected “bro”.

Compatibility

- Provider order is unchanged.
- Request-scoped Gemini API-key round robin is unchanged.
- One Discord message remains one TTS item.
- Gemini Live sessions remain fresh single-turn sessions.
- v0.23.8 cutoff recovery and speakerLabel.speed behavior remain unchanged.
- No new runtime dependency or local AI/TTS component was added.

Upgrade

Preserve .env and data\guilds.json. Replace the old C:\Malay-TTS-Bot files with the v0.23.9 clean package, restore those files, then run setup-clean.cmd. Use the shipped config\settings.json if you want the new separate prompt-profile defaults.
