Malay TTS Bot v0.23.11 — Recovery Evidence & Stale-Tail Hardening

Main fixes
- Prevent fast but complete Gemini Live speech from being mistaken for a cutoff when output transcription is partial or missing. Duration mismatch is now corroborating evidence rather than an independent replay trigger.
- Separate local playback failures from late provider-completion/metadata failures so cleanly finished audio cannot resurrect an unnecessary tail.
- Use mirrored error PCM for objective playback coverage checks when available.
- Suppress stale late recovery after a newer message has already started.
- Invalidate pending post-playback recovery when /clear advances the queue recovery epoch.
- Use a punctuation-independent lexical duration estimate for recovery evidence so ellipses and punctuation do not falsely inflate expected speech length.
- Expand literal-read-aloud routing for common Malay/Manglish question and assistant-like forms without broadly treating ordinary Malay "ke" prepositions as questions.

Regression coverage
- Full fast speech + partial transcript => no duplicate tail.
- Full fast speech + missing transcript => no guessed regenerated tail.
- Clean playback + late completion metadata error => no tail resurrection.
- Genuine very short cutoff still recovers.
- Existing late transcript and no-transcript cutoff recovery remains covered.
- Late recovery after a newer queue item or /clear is suppressed.
- Punctuation-heavy complete speech does not trigger recovery.
- Common no-question-mark forms such as "current event apa", "event baru ke izi", "bro what current event", and "can u check current event" bypass conversational Live.

Validation
- 87 regression tests passed.
- Timing-sensitive recovery suite passed 5 consecutive times on Ubuntu and 5 consecutive times on Windows before release preparation.
- Normal Windows and Ubuntu CI passed after the audited source diff was cleaned of temporary workflows.

Upgrade
Preserve only .env and data\guilds.json from the existing installation. Use the new config\settings.json defaults from this release.
