Malay TTS Bot v0.23.4 — Audit Hardening

Source: v0.23.3 Adaptive Quota Failover clean release.
Priority: latency > quality > features.

Correctness / latency hardening:
- Gemini Live no longer treats a fixed 650 ms post-audio gap as proof the stream ended when completion metadata is missing. The fallback grace now protects the first gap for at least 900 ms and adapts to observed chunk cadence, while generationComplete still closes normal audio promptly.
- Gemini Live cancellation preserves daily-quota, permission and config classification flags so provider-health decisions remain accurate after aborts.
- Gemini 3.1 TTS now classifies HTTP-200 SSE failure events for quota/RPD, auth, permission, request/config, retryability and transport behavior instead of surfacing an untyped generic stream error.
- Cutoff recovery preserves messageId and voiceChannelId so recovered work stays owned by the original Discord message/channel.
- Non-critical guild normalization and automatic voice assignment writes are coalesced off the immediate hot path; explicit settings/privacy mutations remain synchronous and durable.
- FFmpeg executable resolution is cached and invalidates when FFMPEG_PATH changes.
- Speaker-label cleanup preserves Unicode ZWJ sequences and truncates by grapheme cluster.
- Single-instance locking now records a per-process nonce and revalidates the exact stale/corrupt lock record before deleting it, closing the stale-lock replacement race.

Validation:
- Regression suite expanded from 45 to 52 tests.
- Added healthy 700 ms Gemini Live inter-chunk jitter coverage.
- Added HTTP-200 SSE RPD/daily quota coverage.
- Added recovery ownership metadata, grapheme-label, atomic guild JSON backup, stale-lock race and corrupt-lock recovery coverage.
- Node 24 CI passes on Ubuntu and Windows.
- Ubuntu CI also passes the actual FFmpeg volume + limiter + libopus/Ogg encode/decode probe.
- npm ci reports 0 dependency vulnerabilities in CI.

Retained:
- Provider order remains Gemini 3.1 Live -> Gemini 2.5 Live -> Gemini 3.1 TTS -> Google Malay TTS.
- Voice pool remains Charon, Enceladus, Aoede and Despina.
- One Discord message = one TTS item. No message merging and no multi-turn Gemini Live reuse.
- Speaker username remains separate Google Malay TTS audio and is never inserted into Gemini message text.
- Clean audio defaults remain fixedVolume 0.60 and speakerLabel.gain 1.50.
- Free-first / billing-disabled operating model remains unchanged.

Upgrade:
Preserve only .env and data\guilds.json. Do not restore an old config\settings.json. Replace the old folder with the v0.23.4 clean package, restore those two files, then run setup-clean.cmd.
