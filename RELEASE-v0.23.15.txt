Malay TTS Bot v0.23.15 — /ask STOP TTS Button

Main change
- Successful `/ask` replies that are accepted for voice playback now show a red `STOP TTS` button below the embed.
- Pressing the button immediately cancels only that `/ask` spoken answer.
- The rest of the normal TTS queue is preserved and continues automatically.

Safety and ownership
- Only the member who used `/ask` can press that reply's stop button.
- The button targets the existing synthetic `ask:<interaction id>` audio item, so it cannot clear unrelated queued speech.
- If the `/ask` audio already finished, the button becomes disabled as `TTS finished`.
- If voice connection fails, the control is disabled as `TTS unavailable`.

Unchanged behavior
- `/ask` still uses the compact protected embed and speaks only the AI answer.
- Normal user messages keep the existing Gemini Live-first read-aloud path.
- `/ttsoptout`, voice-channel ownership, queue limits, provider fallbacks, cutoff recovery, and speaker-label behavior are unchanged.

Upgrade
Preserve `.env` and `data\guilds.json`. Existing `config/settings.json` remains compatible. Run `setup-clean.cmd` after replacing the application files.
